# Полный курс разработки в Ontobox: Создание приложения «Книжный магазин»

Данное руководство представляет собой детальную текстовую транскрипцию видео-урока по платформе Ontobox (модули Phlox и Flex). В нем пошагово описан процесс создания полноценного веб-приложения с нуля: от проектирования базы данных до сложной настройки пользовательского интерфейса, авторизации и построения аналитических графиков.

---

## ЧАСТЬ 1. Создание объектной модели (Дизайнер Phlox)

### 1.1. Создание пакета (Package)
Вся разработка начинается с создания отдельного пространства имен (пакета) для нашего проекта.
1. В главном окне Phlox перейдите в раздел **Пакеты (Packages)**.
2. Нажмите иконку **`+`** (Создание пакета).
3. Заполните поля:
   * **Идентификатор (Name):** `main`
   * **Заголовок (Title):** `Книжный магазин`

### 1.2. Создание форм (Сущностей предметной области)
Формы являются аналогами классов или таблиц в БД. Мы создадим 5 основных сущностей.

#### Форма 1: Книжный магазин
1. Нажмите **`+`** в столбце "Формы".
2. **Имя:** `КнижныйМагазин` (пишется слитно, с заглавной буквы — это конвенция Phlox).
3. **Заголовок:** `Книжный магазин`.
4. Добавляем поля (нажмите `+` в правом сайдбаре формы):
   * Поле `наименование`: Тип `String`, включите опцию `Required` (обязательное).
   * Поле `книги`: Тип `Книга` (выбрать из списка пакета `main`), включите опции `Multi` (множественное) и `Cascade` (каскадное удаление — при удалении магазина удалятся и книги).

#### Форма 2: Книга
1. Создайте форму **Имя:** `Книга`, **Заголовок:** `Книга`.
2. Добавляем поля:
   * `наименование` (Тип `String`, `Required`).
   * `автор` (Тип `String`, `Required`).
   * `раздел` (Тип `Раздел`, объектное поле, `Required`).
   * `цена` (Тип `Int` / целое число, `Required`).
   * `продано_копий` (Тип `Int`). В атрибутах поля найдите `Default` (По умолчанию) и установите значение `0` (по умолчанию ни одной копии не продано).

#### Форма 3: Раздел
1. Создайте форму **Имя:** `Раздел`, **Заголовок:** `Раздел`.
2. Добавьте поле:
   * `наименование` (Тип `String`, `Required`).

#### Форма 4: Покупатель (Для авторизации)
1. Создайте форму **Имя:** `Покупатель`, **Заголовок:** `Покупатель`.
2. Добавьте поля:
   * `имя` (Тип `String`).
   * `фамилия` (Тип `String`).
   * `логин` (Тип `String`, `Required`).
   * `чеки` (Тип `Чек`, `Multi`, `Cascade` — при удалении покупателя удаляются его чеки).

#### Форма 5: Чек
1. Создайте форму **Имя:** `Чек`, **Заголовок:** `Чек`.
2. Добавьте поля:
   * `дата` (Тип `System/Date` — для этого в поиске типов раскройте системный пакет).
   * `товары` (Тип `Книга`, `Multi`).

### 1.3. Наполнение базы данных первичными объектами
1. Откройте вкладку формы **КнижныйМагазин**. В таблице документов нажмите `+` внизу. Введите наименование: `"Страницы Иркутска"`.
2. Откройте вкладку формы **Раздел**. Создайте три раздела: `"Русская литература"`, `"Зарубежная литература"`, `"Детская литература"`.
3. Откройте вкладку формы **Книга** и создайте несколько книг, заполнив наименование, автора, выбрав раздел из выпадающего списка и указав цену. (Например: "Война и мир", "Л.Н. Толстой", "Русская литература", 850).

### 1.4. Настройка шаблонов имен (Runtitle)
Чтобы в системе объекты отображались не как безликие ID (например, `M_ITEM_23`), а читаемо:
1. Зайдите в форму **КнижныйМагазин**, нажмите кнопку **Runtitle** в верхнем меню.
2. Введите: `Книжный магазин "#{наименование}"`.
3. Зайдите в форму **Раздел**, нажмите **Runtitle**, введите: `#{наименование}`.
4. Зайдите в форму **Книга**, нажмите **Runtitle**, введите: `"#{наименование}" А. #{автор}`.
5. Зайдите в форму **Чек**, нажмите **Runtitle**, введите: `Чек от #{дата.showDate()}` (метод `showDate` отформатирует дату без времени).

## ЧАСТЬ 2. Бизнес-логика (Методы Libretto и Статусы)

Методы создаются в разделе **Methods editor** (Редактор методов) на панели управления формой.

### Метод 1: Ручное добавление книги (Форма `КнижныйМагазин`)
1. Откройте редактор методов в форме `КнижныйМагазин`. Нажмите `+`.
2. **Name:** `добавитьКнигу`, **Title:** `Добавить книгу`.
3. Перейдите на вкладку **Code**. Добавьте параметры метода (`Add Parameter`):
   * `наименование` (String, Required)
   * `автор` (String, Required)
   * `раздел` (Раздел, Required)
   * `цена` (Int, Required)
4. В блоке кода напишите:
```libretto
// Создаем новый объект книги
$b = new Книга;
$b.наименование = наименование;
$b.автор = автор;
$b.раздел = раздел;
$b.цена = цена;
$b.продано_копий = 0;

// Привязываем созданную книгу к текущему магазину
$this.книги += $b;
```
*Нажмите Save. Теперь книгу можно добавить через вызов метода прямо из интерфейса Phlox.*

### Метод 2: Покупка книг пользователем (Форма `КнижныйМагазин`)
1. Создайте метод **Name:** `купитьКниги`, **Title:** `Купить книги`.
2. Добавьте параметр:
   * `книги` (Тип `Книга`, включить галочку `Multi` — множественный выбор, `Required`).
3. В блоке кода напишите логику формирования чека и обновления счетчиков:
```libretto
// 1. Формируем чек
$чек = new Чек;
$чек.дата = getNow(); // системный метод получения текущего времени
$чек.товары = книги;

// 2. Привязываем чек к авторизованному покупателю
// m/user - обращение к текущему залогиненному пользователю
m/user.чеки += $чек;

// 3. Увеличиваем счетчик продаж
for $книга in книги {
    $книга.продано_копий = $книга.продано_копий + 1;
}
```

### Настройка Статусов (States) для формы `Покупатель`
1. Откройте форму `Покупатель`, нажмите кнопку **States** (Статусы).
2. Нажмите `+` и создайте статус: `Обычный`. Нажмите на иконку звездочки рядом с ним — это сделает его **статусом по умолчанию** для всех новых покупателей.
3. Нажмите `+` и создайте второй статус: `Постоянный`.

### Метод 3: Обновление статуса покупателя (Форма `Покупатель`)
1. Откройте редактор методов для `Покупатель`.
2. Создайте метод **Name:** `сделатьПостоянным`, **Title:** `Сделать постоянным`.
3. Код метода:
```libretto
// Если у покупателя больше 2 чеков, переводим его в статус Постоянный
if ($this.чеки.size() > 2) {
    $this.state = m/state.Постоянный;
}
```

## ЧАСТЬ 3. Создание Веб-интерфейса (Конструктор Flex)

### 3.1. Импорт модулей и настройка Авторизации
1. Нажмите на иконку человека в правом верхнем углу Phlox -> **Перейти во Flex**.
2. В левом меню нажмите **Settings** -> **Import/Export**.
3. Импортируйте системные пакеты (поставьте галочки и нажмите Import):
   * `system.flex`
   * `system.authentication`
4. В меню выберите **Authentication settings**. Заполните конфигурацию:
   * **User form:** Выберите класс `main/Покупатель`.
   * **Login field:** Выберите поле `логин`.
   * **Required fields in SignUp:** Отметьте `имя` и `фамилия`.
   * Нажмите `Install Authentication Module and Pages`. Система автоматически сгенерирует страницы входа (`signin`) и регистрации (`signup`).

### 3.2. Создание Главной страницы (Main Page)
1. В левом меню в блоке **Pages** нажмите `Add Page`.
2. **Page name:** `mainPage`, **Page title:** `Главная`.
3. Вернитесь в **Authentication settings** и в блоке *Special pages -> Welcome page* выберите `mainPage` (чтобы после логина перебрасывало сюда).

### 3.3. Наполнение страницы: Заголовок и Сетка
1. Откройте `mainPage`. Вы увидите пустой компонент `Root`.
2. Нажмите на него и выберите тип **Layout** -> **Simple row/column**. Оставьте 1 колонку.
3. Внутри Layout добавьте первую подкомпоненту (**Add subcomponent**). Выберите тип **Code**.
4. Вставьте HTML-код заголовка с динамической подстановкой:
```html
<!-- allКнижныйМагазин()[0] берет первый магазин из базы -->
<h2>Книжный магазин "#{allКнижныйМагазин()[0].наименование}"</h2>
```

### 3.4. Вывод списка книг и кнопки "Купить"
1. Добавьте вторую подкомпоненту. Тип: **Layout** -> **Simple row/column**. В настройках компонента (иконка шестеренки) установите 2 колонки (одна для книг, другая для профиля).
2. В левой колонке выберите тип **Content** -> **Selection** (Выборка данных).
   * **Query (Запрос):** `allКнижныйМагазин()[0].книги`
   * **Object layout settings (Вид):** `Table` (Таблица).
   * **Fields (Поля):** Отметьте галочками `наименование`, `автор`, `раздел`, `цена`, `продано_копий`.
3. Внутри этого компонента `Selection` добавьте подкомпонент (**Add subcomponent**) -> назовите его `btnBuy`.
4. Выберите для `btnBuy` тип **Content** -> **Methods Panel**.
   * **Query (Запрос для метода):** `allКнижныйМагазин()[0]`.
   * **Method:** Выберите `купитьКниги`.
   * *Результат: под таблицей книг появится кнопка, при нажатии на которую откроется модальное окно для выбора книг из таблицы и совершения покупки.*

### 3.5. Правая колонка: Профиль пользователя
1. В правой колонке выберите тип **Content** -> **Selection**.
   * **Query:** `m/user` (данные текущего пользователя).
   * **Object layout settings:** `Simple document` (Вывод карточкой, а не таблицей).
   * **Fields:** Выберите `имя`, `фамилия`, `логин`, `Status` (Статус).

### 3.6. Вывод списка чеков и создание Псевдополя
1. Добавьте подкомпоненту под профилем пользователя. Тип **Content** -> **Selection**.
   * **Query:** `m/user.чеки`
   * **Object layout settings:** `Unfoldable` (Раскрывающийся список/Аккордеон).
   * **Fields:** Оставьте `дата`.
2. В чеке нет поля "Общая сумма". Мы рассчитаем ее на лету. В блоке Fields нажмите **Add Field** -> **Empty Pseudo**.
   * **Title:** `Сумма`
   * Нажмите `Edit` у созданного псевдополя.
   * **Evaluated Expression:** `$this.товары.sum(цена)`. (Суммируем поле `цена` по всем товарам в `$this` чеке).
3. Чтобы чеки можно было развернуть и посмотреть купленные товары, внутри этого `Selection` добавьте подкомпоненту. Тип **Content** -> **Selection**.
   * **Query:** `$this.товары`
   * **Object layout:** `Table`.
   * **Fields:** `наименование`, `автор`, `цена`.

### 3.7. Связывание событий (Listeners)
Чтобы таблица чеков обновлялась моментально после нажатия кнопки "Купить":
1. Откройте настройки компонента, отвечающего за список чеков (шестеренка на блоке Selection чеков).
2. В правом меню найдите **Listeners** (Слушатели) -> **Add listener**.
3. Выберите из списка компонент вашей кнопки (например, `Selection->MethodsPanel`).
*Теперь компонент чеков «слушает» кнопку и обновляет данные без перезагрузки всей страницы.*

## ЧАСТЬ 4. Страница Аналитики (Plotly)

### 4.1. Создание страницы и графика
1. Создайте новую страницу: **Page name:** `statPage`, **Page title:** `Статистика`.
2. В компоненте `Root` выберите тип **Bootstrap** (иконка шестеренки с доп. библиотеками) -> **Plot Trace** (График Plotly).
3. Настройте параметры графика:
   * **Title:** `Продажи по разделам`
   * **Type (Тип графика):** `Bar` (Столбчатая диаграмма)
   * **X Title:** `Раздел`
   * **Y Title:** `Выручка (руб)`

### 4.2. Написание логики осей графика (X и Y)
1. **X Data (Ось X - Категории):**
   Нужно получить названия всех разделов.
   ```libretto
   allРаздел().наименование
   ```
2. **Y Data (Ось Y - Значения):**
   Нам нужно пройтись по каждому разделу, найти все проданные книги этого раздела и умножить их количество на цену. Для трансформации списков используем метод `map`.
   ```libretto
   allРаздел().map( $r -> 
       allКнижныйМагазин()[0].книги
       .where($k -> $k.раздел == $r)
       .sum(продано_копий * цена) 
   )
   ```
   *Разбор кода: Берем все разделы (`allРаздел`). Для каждого раздела (`$r`) заходим в магазин, фильтруем книги (`where`), где раздел книги равен текущему разделу (`$k.раздел == $r`), и суммируем выручку (`sum`).*

### 4.3. Тестирование
1. Нажмите зеленую кнопку **Run** (Запуск) в правом верхнем углу Flex.
2. Пройдите регистрацию (Sign Up), введите логин, имя, фамилию.
3. На Главной странице выделите галочками несколько книг и нажмите "Купить книги".
4. Список чеков обновится автоматически благодаря Listener. Псевдополе "Сумма" рассчитает итог. Раскройте чек, чтобы увидеть таблицу товаров.
5. Перейдите на страницу Статистики и убедитесь, что столбчатая диаграмма корректно отображает суммы продаж по каждому разделу.
